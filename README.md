# Delta Pharma (Pvt.) Ltd. website

Static site (HTML5, CSS3, vanilla JS) for GitHub Pages. No build tooling needed to deploy.

## Structure
- `*.html` – pages (generated by `build.py`; commit the output)
- `css/styles.css`, `js/main.js`, `assets/`
- `build.py` – edit copy/nav/footer once, run `python3 build.py`

## Before going live (replace placeholders)
1. `build.py`: set `SITE` (your Pages URL) and `FORM` (create a free form at formspree.io, copy its ID).
2. Replace `info@example.com`, `+92 000 0000000`, street address, and every `[bracketed]` item (founding year, manufacturing licence, GMP details). Only publish certifications the company actually holds.
3. Run `python3 build.py`.

## Deploy
```
git init && git add . && git commit -m "Initial Delta Pharma site"
git branch -M main
git remote add origin https://github.com/<user>/delta-pharma.git
git push -u origin main
```
Then on GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / root**. The site appears at `https://<user>.github.io/delta-pharma/` within a minute or two. For a custom domain, add a `CNAME` file and set DNS.
